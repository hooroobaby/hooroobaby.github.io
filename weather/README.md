# Weather Page Setup

## Quick Start

1. Copy the example config:
   ```bash
   cp config.example.js config.js
   ```

2. Edit `config.js` and add your API key:
   ```javascript
   const WEATHER_CONFIG = {
       API_KEY: 'your_api_key_here'
   };
   ```

3. Get your free API key at: https://openweathermap.org/api
